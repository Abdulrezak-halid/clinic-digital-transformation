# Proje özeti

Amaç: kâğıt ağırlıklı hasta iletişim, randevu, katılım ve paket takibini güvenilir idari uygulamaya dönüştürmek. Kullanıcılar yönetici, fizyoterapist ve resepsiyondur. İlk pilot tek şubelidir. Halka açık mersinfiziktedavi.com ile entegrasyon yoktur.

Başarı: yeniden yüklemede kayıt korunması; eş zamanlı çakışan randevuların reddi; tekrar gönderimde tek seans tüketimi; yetkisiz API erişiminin reddi; geri yükleme ve kullanıcı kabulü. Faz 0 kararları: idari çekirdek, Türkiye barındırma hedefi, yalnız tamamlanan seansta düşüm, personel/hasta/kaynak kapasitesi.

Paydaşlar: Hamit Gümüş iş sahibi; resepsiyon operasyon kullanıcısı; teknik işletmeci bakım ve yedek sorumlusu; hukuk danışmanı veri ve mevzuat kontrolü. İsim ve operasyon saatleri pilot öncesinde netleşmelidir.
